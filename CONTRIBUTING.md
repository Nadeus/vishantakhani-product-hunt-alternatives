# Contributing

Thanks for helping makers find the right places to launch! Suggestions, corrections and new platforms are all welcome.

## Adding a platform

1. The platform must be **live** and **accept launches or listings** from makers (no dead sites, no pure link farms).
2. Add it to the **right section** of the README, in the same format as the entries around it:

   ```markdown
   ### [Platform name](https://example.com)
   One or two plain sentences: what it is and how a launch or listing works (free / paid, badge, link type if known).
   **Best for:** who it suits.
   ```

3. Keep descriptions **factual and neutral**: no marketing claims, no prices you can't link to.
4. One platform per pull request, please. Say in the PR description whether you run the platform.

## Fixing information

Pricing, launch formats and link rules change. If something is out of date, open a pull request with the fix and a link to the page that shows it, or [open an issue](../../issues).

## Removals

Platforms that go offline, stop accepting submissions or turn into spam will be removed.
